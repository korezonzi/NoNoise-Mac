# NoNoise Mac 利用ガイド

NoNoise Mac は、通話中の雑音をリアルタイムで消してくれるメニューバーアプリです。キーボードの打鍵音やエアコンの音を、マイクの音から自動でカットします。音声の処理はすべて Mac の中だけで完結します。初回セットアップは5分ほどで終わります。

## 1. インストール（初回のみ・約5分）

1. 下のリンクから `NoNoiseMac.pkg` をダウンロードします。常に最新版がダウンロードされます。
   - ダウンロードリンク: https://github.com/korezonzi/NoNoise-Mac/releases/latest/download/NoNoiseMac.pkg
   - Google Drive にも同じファイルを置いています（フォルダのリンクは Slack の案内に載せます）
2. ダウンロードした `NoNoiseMac.pkg` をダブルクリックします。
3. 「開けませんでした」という趣旨の警告が出ます（Apple が安全性を確認できない、という内容）。無署名のアプリでは必ず出るもので、故障ではありません。「完了」を押して閉じます。

   ![スクショ①: ブロックダイアログ]()

4. 「システム設定」を開き、「プライバシーとセキュリティ」を選びます。画面を下の方までスクロールすると、「"NoNoiseMac.pkg" は Mac を保護するためにブロックされました」のような一文の右側に「このまま開く」ボタンがあります。これを押します。

   ![スクショ②: 「このまま開く」ボタン]()

5. パスワードの入力か Touch ID を求められるので、管理者パスワードを入力します。続けて確認のダイアログが出るので「開く」を押すと、インストーラが起動します。
6. インストーラの案内に沿って進めます。最後にもう一度、管理者パスワードの入力を求められます。アプリ本体（/Applications に入ります）と仮想マイクドライバ「NoNoise Mic」「NoNoise Speaker」を一度にインストールするための認証です。
7. インストール中、Mac の音が3秒ほど途切れます。オーディオの仕組みを裏側で再起動しているだけなので、故障ではありません。
8. 「インストールが完了しました」と表示されたら完了です。

   ![スクショ③: インストーラ完了]()

9. 通話アプリ（Meet、Zoom、Slack など）のマイク設定で「NoNoise Mic」を選びます。これで準備完了です。

手順3〜5の「ブロックを解除する」操作は、今回のインストールでは1回で済みます。次にアップデートで新しい pkg を実行するときは、また同じ操作が必要になります（「6. アップデート」を参照）。

## 2. 初回の許可

NoNoise Mac を初めて起動すると、マイクへのアクセスを許可するダイアログが表示されます。「許可」を押してください。

ダイアログが出なかった場合、または誤って拒否してしまった場合は、次の手順で許可できます。

1. 「システム設定」を開く
2. 「プライバシーとセキュリティ」を選ぶ
3. 「マイク」を選ぶ
4. 「NoNoise Mac」をオンにする

## 3. ふだんの使い方

メニューバーのアイコンをクリックすると、操作パネルが開きます。「ノイズ除去」は起動時から ON になっているので、特に操作は不要です。

強さのモードは「自動」「強」「中」「弱」「カスタム」から選べます。基本的には「自動」のままで問題ありません。周囲のノイズの量に合わせて、除去の強さが自動で変わります。

オープンオフィスなど、周りで人が話している場所では、モードを「強」にしてください。「自動」は周囲の話し声を静かな部屋と誤認して、除去が弱くなることがあります。なお、周りの人の声そのものは、どのモードでも完全には消えません（人の声を残す仕組みのためです）。

周りの人の声が相手に届いてしまうときは、「周囲の声を抑える」を試してください（メニューバーの操作パネル、または「設定」→「全般」にあります）。自分が話していない間、周囲の話し声を絞る機能です。まず「Medium」で試し、それでも残るなら「High」、自分の声の出だしが欠けると感じたら「Low」にしてください。ヘッドセットなど口元にマイクがある人向けで、自分が話している最中に重なる声までは消えません。

Mac を起動するたびに手動で立ち上げたくない場合は、「設定」→「全般」の「ログイン時に自動起動」をオンにしておくと、次回から自動で起動します。

## 4. 相手の音声もクリアにしたいとき（任意）

通話相手側の雑音も消したい場合は、「相手の音声もクリアに」という機能を使います。任意の機能なので、使わなくても支障はありません。モードは2つあります。

「通話アプリのみ（推奨）」は、通話アプリの音だけをきれいにします。この場合、通話アプリのスピーカー設定で「NoNoise Speaker」を選ぶ必要があります。選び忘れると音は何も変わりません。忘れているときはアプリ側にも確認メッセージが表示されます。

「全システム音声」は、音楽やブラウザの音も含めて Mac から出るすべての音を処理します。初めて ON にすると、システム音声を録音する許可を求めるダイアログが出るので「許可」を押します。拒否してしまった場合は、「システム設定」→「プライバシーとセキュリティ」→「画面収録とシステムオーディオ録音」で「NoNoise Mac」をオンにし、機能をいったん OFF にしてからもう一度 ON にしてください。

この機能を使うには macOS 14.4 以上が必要です。

内蔵スピーカーとマイクで話しながらこの機能を使うと、自分の声がスピーカーから流れ、それをマイクが拾って相手にエコーとして返ってしまうことがあります。イヤホンを使えばこの問題は起きません。イヤホンが使えない場合は、この機能を OFF にしてください。次の章に、もうひとつの対処法があります。

## 5. 内蔵スピーカーで話す人へ（ベータ機能）

イヤホンなしで内蔵スピーカーから話すことが多い人向けに、試験的な機能を用意しています。「設定」→「実験的機能」→「エコーキャンセル付きマイク取り込み（ベータ）」です。

ON にして、ステータスに「AEC有効」と表示されれば動作しています。この状態であれば、内蔵スピーカーのまま「相手の音声もクリアに」を使っても、自分の声がエコーとして返りにくくなります。

キーンという高い音（ハウリング）や、相手側でのエコーが起きた場合は、すぐに OFF に戻してください。手元のテストでは、まれにハウリングが残ることがありました。この機能を使わなくても、他の機能への影響はありません。

## 6. アップデート

NoNoise Mac に自動更新の仕組みはありません。新しいバージョンが出たときは Slack で案内します。案内が来たら、同じダウンロードリンクから pkg を取得し直し、「1. インストール」と同じ手順を行ってください。ブロック解除の操作も、更新のたびに毎回必要です。

## 7. 困ったとき

| 症状 | 対処 |
|------|------|
| 通話アプリのマイク一覧に「NoNoise Mic」が出ない | 通話アプリを再起動する。それでも出なければ pkg をもう一度実行する |
| 相手に自分の声が届かない | メニューバーで入力が「自動」か、実際に使っているマイクになっているか確認する。マイクの許可（「2. 初回の許可」）も確認する。通話アプリのマイクが「NoNoise Mic」になっているかも確認する |
| 相手に自分の声がエコーで返る | イヤホンに切り替える。「相手の音声もクリアに」を OFF にする |
| 他のアプリの音が消えたまま戻らない | メニューバーの「終了」から NoNoise Mac を終了し、もう一度起動する。直らない場合は Mac 自体を再起動する |
| マイクが急に無音になる | Mac を再起動する。アクティビティモニタなどから強制終了すると起こることがあるので、終了は必ずメニューバーの「終了」から行う |
| アンインストールしたい | /Applications の「NoNoise Mac」をゴミ箱に入れる。仮想マイクの削除には別の作業が必要なので、Slack で土屋に依頼する |

上記で解決しない場合は、Slack で土屋まで連絡してください（DM で大丈夫です）。

## 8. プライバシー

音声の処理はすべてその Mac の中だけで行われます。マイクの音や通話の内容が外部のサーバーに送られることはありません。サブスクリプションやアカウント登録も不要です。
