# NoNoise Mac — チームメンバー向けインストールガイド

> Status: DRAFT（Phase 4 で確定。配布物のファイル名・バージョンは初回リリース時に更新）

## 動作要件

- Apple Silicon の Mac（M1 以降）
- **macOS 14.4 (Sonoma) 以上** — 受信クリーンアップ（相手側ノイズ除去）の必須要件
- Intel Mac・Windows は非対応

## インストール手順（無署名版）

現在の配布物は Apple の開発者署名がない「無署名ビルド」です。初回起動時に
Gatekeeper がブロックするため、以下の手順が必要です（初回のみ）。

### 1. アプリ本体

1. 配布された `NoNoiseMac-<version>.pkg`（推奨）をダブルクリック。
   ブロックされた場合: **システム設定 → プライバシーとセキュリティ** を開き、
   下部に表示される「"NoNoiseMac..." は開発元を確認できないため…」の右の
   **「このまま開く」** を押す。
2. zip 配布の場合は `NoNoiseMac.app` を `/Applications` に移動してから、
   **右クリック →「開く」→「開く」**（ダブルクリックではなく右クリックが必要）。
3. それでも開けない場合（ターミナルでの代替手段）:
   ```bash
   xattr -dr com.apple.quarantine /Applications/NoNoiseMac.app
   ```

### 2. 仮想マイクドライバ（NoNoise Mic）

通話アプリに「NoNoise Mic」を見せるためのドライバです。管理者パスワードが必要です。

```bash
cd <配布フォルダ>
sudo ./install-driver.sh
```

成功すると、システム設定 → サウンド → 入力に **NoNoise Mic** が現れます。

### 3. 初回の権限許可（TCC）— この順番で

1. **マイク**: NoNoise Mac 初回起動時にプロンプトが出る → **許可**。
   （出ない場合: システム設定 → プライバシーとセキュリティ → マイク → NoNoise Mac を ON）
2. **システムオーディオ録音**: 受信クリーンアップ（「相手の音声もクリアに」トグル）を
   初めて ON にしたときにプロンプトが出る → **許可**。
   拒否してしまった場合: システム設定 → プライバシーとセキュリティ →
   画面収録とシステムオーディオ録音 で NoNoise Mac を許可 → トグルを一度 OFF→ON。

### 4. 通話アプリ側の設定

- **マイク**: 「NoNoise Mic」を選択（Zoom / Meet / Discord / OBS 共通）。
- **スピーカー**: そのまま（通常のスピーカー/イヤホン）。
  「NoNoise Speaker」モードを使う場合のみ、通話アプリのスピーカーに
  「NoNoise Speaker」を選択（アプリ内の案内に従う）。

## 使い方の要点

- メニューバーのアイコンから操作。**AI ノイズ除去はデフォルト ON**。
- 相手側のノイズも消したいとき: 「相手の音声もクリアに」を ON。
- **スピーカー（イヤホンなし）で通話するとき**: エコーキャンセル付きマイク取り込みが
  有効なら、受信クリーンアップ ON のままスピーカー通話ができます。
  （設定 → 実験的機能 のステータスが「AEC有効」であることを確認）

## トラブルシューティング

| 症状 | 対処 |
|------|------|
| 通話アプリに NoNoise Mic が出ない | ドライバ再インストール（`sudo ./install-driver.sh`）→ 通話アプリを再起動 |
| 音が届かない | メニューバー → 入力デバイスが「自動」か正しいマイクか確認。マイク権限を確認 |
| 相手にエコーが返る（スピーカー通話） | 設定 → 実験的機能 のステータスを確認。「従来方式で動作中」の場合はイヤホンを使うか受信クリーンアップを OFF |
| 他のアプリの音が消えたまま | NoNoise Mac を再起動（muted tap の解放）。直らなければ Mac を再起動 |
| 診断ログの取得 | `log stream --predicate 'subsystem == "com.korezonzi.NoNoiseMac.r2"' --style compact` |

## アップデート

アプリ内蔵の Sparkle 自動更新が新バージョンを通知します。手動確認はメニューバー →
設定から。

## プライバシー

音声処理は 100% この Mac の中で完結します（DeepFilterNet3 の CoreML ローカル推論 +
macOS の音声処理）。音声データが外部に送信されることはありません。
